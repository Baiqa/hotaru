# ADR-0008: Бесплатные LLM-тарифы и цепочка запасных провайдеров

**Статус:** Принято (временно: «платный тариф, когда все функции заработают»)
**Дата:** 2026-11-07 (решение), 2026-11-08…10 (цепочки)
**Принимал:** владелец проекта

## Контекст

Бюджета на LLM нет. LLM нужен в четырёх местах: серая зона кластеризации, извлечение фактов, группировка фактов, синтез. Бесплатный тариф
Gemini даёт примерно **500 вызовов чата в сутки на `gemini-3.1-flash-lite`, общие для всех шагов**, и около 1000 запросов эмбеддингов (отдельная
квота). Сброс около 08:00 UTC. Спрос при потоке 400–1100 статей в сутки оценён в 2500–3000 вызовов.

## Решение

- Основа: бесплатный Gemini. Платный тариф откладывается до момента, когда все функции работают (решение владельца).
- Цепочки запасных моделей:
  - **Серая зона:** `gemini-3.1-flash-lite` → Groq (`openai/gpt-oss-120b`) → `gemini-3.5-flash-lite`.
  - **Группировка фактов и синтез:** Gemini (основная, затем `gemini-3.1-flash-lite-preview`) → Groq.
  - **Извлечение фактов:** только Gemini, без Groq.
- При 429 с дневной квотой (`PerDay`, ответ несёт `retryDelay` около 46 000 с) повторы бессмысленны: шаг сразу завершается (быстрый отказ
  по дневной квоте), а не ждёт.
- Казахские источники не нужны; авторизация допустима, но отдельной задачей.

## Рассмотренные варианты

| Вариант | Оценка |
|---|---|
| Платный Gemini сейчас | Отложен: нет бюджета |
| OpenRouter | Отвергнут 2026-09-27 (один провайдер вместо двух) |
| Cerebras, Mistral | Оценены в ноябре 2026 как «хуже или неопределённее» бесплатного Groq |
| Groq как третий уровень | Выбран: около 1000 запросов в сутки без карты, OpenAI-совместимый API с JSON-режимом |
| `gemini-3.1-flash-lite-preview` как «вторая квота» | **Не работает:** квота общая с основной моделью (проверено 2026-11-10). Остаётся в коде как запасная модель, ёмкости не добавляет |

## Последствия

- Лимиты Groq: 1000 запросов в сутки, 8000 токенов в минуту, **200 000 токенов в сутки**; упирается в токены (около 350–450 токенов на вызов
  серой зоны, то есть 450–570 вызовов).
- Качество запасных уровней ниже: согласие Groq с Gemini на серой зоне 82% (45 пар); `gemini-3.5-flash-lite` согласен с основной моделью на 76%
  (в 7 из 15 «same» отвечает «related»). Дневной лимит `gemini-3.5-flash-lite` **не измерен**.
- Ключ Groq нужен пользователю самому (регистрация), без ключа код работает как раньше и просто не использует Groq.
- Квота делится между шагами: `hotaru-synthesize` и `hotaru-group-claims` нельзя запускать одновременно, они начинают голодать друг друга.
- Остаётся зависимость от нестабильных названий моделей и условий бесплатных тарифов провайдеров.
