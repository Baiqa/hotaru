## Формат и правила

- Файл `NNNN-краткое-имя.md`, статусы: Предложено, Принято, Заменено (с номером новой записи), Отменено.
- Решение не переписывается: если оно меняется, пишется новая запись, а у старой статус становится «Заменено ADR-NNNN».
- Ссылки на код и планы указывайте по пути; если файл удалён, дайте коммит.
- «Принимал» везде одно лицо, владелец проекта: команды нет, поэтому отдельного согласования не требуется.
