# ADR-0012: Web-first PWA с Service Worker, Android позже через Capacitor

**Статус:** Принято; установка на реальный телефон не проверена
**Дата:** 2026-09 (платформа, спецификация §2), 2026-11-10 (реализация PWA)
**Принимал:** владелец проекта

## Контекст

Продукту нужны оффлайн-чтение, установка на главный экран и ощущение приложения, но не хочется поддерживать несколько кодовых баз.

## Решение

- **Web-first:** Next.js (App Router) + TypeScript + Tailwind, SSR для быстрой первой отрисовки, один код на веб и мобильные. Android позже
  оборачивается Capacitor-обёрткой над PWA (push, шаринг, оффлайн без переписывания); push только через Capacitor-сборку (этап 6).
- **PWA:** манифест (`display: standalone`), иконки (192 и 512, генерируются `ImageResponse`, образ «светлячок»), `viewport-fit=cover` и safe area.
- **Service Worker** (`web/public/sw.js`, регистрируется только в production): статика `/_next/static` и иконки cache-first (имена с хешем);
  страницы `/`, `events`, `stories`, `articles` по **белому списку**: сеть в приоритете, кеш последних **40** страниц для чтения без сети;
  остальные переходы: сеть, без сети страница `/offline`.
- **Скелетоны** только на главной (`(list)/loading.tsx`): на страницах с `notFound()` Suspense превращает настоящий 404 в мягкий 200.

## Рассмотренные варианты

Нативные приложения явно не рассматривались: спецификация выбирает «web-first PWA, Android-обёртка через Capacitor на поздних этапах».
Все страницы `force-dynamic` (SSR на каждый запрос): статического HTML для предкеша нет, поэтому кеш страниц наполняется при просмотре.

## Последствия

- Проще: одна кодовая база; оффлайн-чтение последних 40 страниц.
- Белый список страниц исключает `/admin` из кеша Service Worker (дополнительно `/admin/*` отдаётся с `Cache-Control: no-store`).
- **Не реализовано:** свои переходы между экранами и жест «назад», View Transitions (экспериментальные), скелетоны на страницах с `notFound()`, push.
- **Не проверено:** установка на реальный телефон, safe area на устройстве с вырезом, поведение при реальном отключении сети (проверялось только
  в десктопном браузере и эмуляции).
